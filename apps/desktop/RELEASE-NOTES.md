# 音乐播放器 0.1.0

首个公开版本。带 3D 粒子视觉的本地音乐播放器，Windows 桌面端。

## 下载

**[MusicPlayer-Setup.exe](https://github.com/JasperBo-w/music-player/releases/latest/download/MusicPlayer-Setup.exe)** · 94.92 MB · Windows 10 1809 (x64) 及以上

安装包 SHA-256：

```
ca0075cfef2d54542029c1d545304c7e02d14a233a1b0feb5d323f0e9e21b331
```

下载后可在 PowerShell 里核对：

```powershell
Get-FileHash .\MusicPlayer-Setup.exe -Algorithm SHA256
```

## 这一版有什么

- **3D 粒子可视化** —— 基于 Three.js 的实时粒子舞台，随节拍律动。多种预设效果与配色方案可切换
- **逐字歌词** —— 逐字高亮渲染，支持独立桌面歌词窗（可拖动、可置顶）
- **本地曲库与歌单** —— 扫描本地音乐，管理歌单、播放队列与播放历史
- **音源接入** —— 支持扫码 / 手机号登录自己的账号，读取自己的歌单与收藏
- **可调外观** —— 强调色、玻璃磨砂强度、粒子密度均可调；低配机器可一键关掉高开销特效

## 安装说明

**Windows 会提示「已保护你的电脑」** —— 这是未购买代码签名证书的应用都会遇到的
SmartScreen 提示，不是病毒告警。点「更多信息」→「仍要运行」即可。

如果杀毒软件拦截，请把安装目录加入白名单。

## 卸载

控制面板 →「程序和功能」→ 找到 MusicPlayer 卸载。卸载时会询问是否一并删除本机
用户数据（登录态、歌单缓存、设置）。

## 这个软件不做什么

这是一个播放器客户端：**不托管、不存储、不分发任何音频文件**。软件内的音源能力
用于播放你自己有权访问的内容与接入你自己的账号，请遵守你所在地区的法律法规及
各内容平台的服务条款。
